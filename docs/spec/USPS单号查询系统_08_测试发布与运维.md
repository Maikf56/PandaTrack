# USPS 单号查询系统 08：测试、发布与运维

## 1. 模块目标

建立从代码检查到 Linux 云服务器验收、真实 Provider 验收、容量测试、备份恢复、发布、观察和回滚的完整交付链路，确保生产只运行可追溯、已验证的固定制品。

## 2. 功能范围

- 自动化 CI：依赖安装、静态检查、单元/集成/E2E、构建、接口和黑名单扫描。
- 云服务器开发联调、验收/压测和生产切换演练。
- 真实 Provider、A/B、Redis、SSE、Worker、计费和前端全链路验收。
- 监控、告警、日志、备份、恢复、回滚、故障注入和发布记录。

## 3. 关键设计

### 3.1 测试分层

- 单元：清洗、解析、状态映射、错误分类、计费窗口、幂等和权限。
- 集成：A/B outbox、投影、Redis 重建、SSE 快照恢复。
- E2E：客户直接提交→202→进度→轨迹，管理员权限和账务操作。
- 百万级受理：单次 1,000,000 条 / 64 MiB 上传、集合化计费判定、按并发环境数均衡分批断点续写、租户公平队列和 SSE 按批次聚合；验证不静默截断、不重复扣费、不逐行推送。
- Linux 验收：systemd/Nginx、迁移、备份恢复、真实浏览器运行时、真实 USPS 样本和 1/2/5/10 环境容量。
- 故障注入：Worker 强杀、Redis 清空、网络超时、解析失败、403/429/挑战、数据库恢复和回滚。
- 外部依赖三项冒烟（先于任何外部源定稿/启用）：① 目标 Linux 上直连与浏览器两种形态可达性；② 匿名真实数据能否取得；③ 付费/会员/限额门槛。17TRACK 因匿名演示卡与额度制已据此弃用，不进入本方案链路。

### 3.2 发布流程

1. 选择 commit，执行 CI 全部检查并生成制品、依赖清单和 SHA-256 摘要。
2. 在云服务器验收区部署同一制品，运行迁移、健康检查、核心 E2E、真实 Provider 验收和容量观察。
3. 备份成功、迁移向前兼容、密钥/数据/域名隔离检查通过后审批发布。
4. Linux 生产以 release 目录/镜像标签原子切换，发布后执行 smoke test 和指标观察。
5. 指标超过回滚阈值时停止放量并切换上一版本；数据库破坏性问题按恢复流程处理，不能只回滚应用。

### 3.3 备份和恢复

PostgreSQL、配置元数据和必要制品备份加密、异地保存、访问受限；浏览器 profile/Cookie 按单独策略处理，不默认进入数据库备份。每日 pg_dump 时 RPO 只能表述为不超过 24 小时；WAL/PITR 未实测前不承诺零丢单。恢复要校验 A/B 行数、关键内容摘要、投影版本、账务流水和任务状态。

### 3.4 监控与告警

监控 API 延迟/错误、登录失败、队列深度、最老任务、Worker/profile、Provider 成功率/解析率/P95、403/429/挑战/额度、A/B lag、SSE、数据库磁盘、备份和证书。告警分为需观察、需降载、需暂停和需建自动恢复流程；所有告警均关联处置手册。

### 3.5 恢复目标、成本复核与未完成项

- 恢复目标按已定口径执行：每日备份场景 RPO ≤24 小时、RTO ≤4 小时；未实测 WAL/PITR 前不承诺 0 丢单。恢复必须先停写，再逐表比对行数、内容摘要、投影版本、账务流水和任务状态。
- 容量记录必须区分空库与真实负载：旧上限下干净库万条 commit 曾为 0.512 s，连续多轮压测后历史数据与后台排队会升到 1.8–2.1 s；该数字只作为参考基线，不代表当前 1,000,000 条受理能力。空库数字不是长期承诺；生产前须在接近真实数据量、后台并行、云上 SSD 条件下重新标定百万级受理 P95 ≤60 s 目标与 百万级排队表现。
- 未完成项必须显式保留在发布记录：真实 Provider 生产启用、GitHub Actions 首次实跑（仓库无远端）、systemd/Nginx/TLS 完整生产链路、备份加密与异地副本、WAL/PITR 时间点恢复、自动回滚链路、云上容量标定。
- `requirements.lock` 是精确版本冻结，不是哈希锁；Windows 浏览器 PoC 依赖不进入 Linux 服务端锁文件或发布制品。

## 4. 模块间依赖

依赖 01 的环境和发布基础、02 的真实 Provider 验收、03/04 的管理和客户流程、05/06/07/09 的数据/业务/调度/契约实现。反向为全模块提供验收、发布和故障恢复检查。

## 5. 交付内容

- CI 检查、构建制品、依赖清单、制品摘要和发布记录。
- 单元/集成/E2E/Linux/真实 Provider/容量测试报告。
- 部署、迁移、备份、恢复、回滚和故障处置手册。
- 监控面板、告警规则、Provider 暂停和自动恢复流程记录。
- RPO/RTO 实测报告及未达到项清单。
- 外部依赖三项冒烟记录、容量负载敏感性记录、CI 首次实跑与云上容量标定证据；未完成项按清单列明，不写成通过。
